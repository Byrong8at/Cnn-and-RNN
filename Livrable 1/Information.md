# Livrable 1

## Utilité de chaque fichier

- **Livrable1.ipynb** : il s’agit du notebook principal de notre livrable. Il contient les différentes architectures, les explications associées ainsi que les différents graphiques obtenus au cours du projet.

- **Dl_dataset.py** : ce fichier Python est utilisé par le notebook. Il contient les différentes fonctions permettant l’installation et le téléchargement automatiques et complets des datasets ainsi que des modèles créés pour ce livrable.

- **requirements.txt** : ce fichier permet d’installer automatiquement l’ensemble des bibliothèques nécessaires au fonctionnement du projet.

- **Le dossier `src`** : il contient les images utilisées dans le notebook afin d’illustrer et d’afficher les différents résultats.

- **.gitignore** : ce fichier est principalement utilisé pour notre dépôt GitHub. Il permet d’ignorer certains fichiers et dossiers lors des *push*, afin d’éviter de surcharger inutilement le dépôt.
